ES Agents makes AI tools for small UK businesses such as plumbers, electricians, roofers, salons, garages and cafés. We are a team of two.

## What it is

- **Website Agent:** a chat widget that answers a visitor's questions using only the client's own facts, so it can't make things up. There is a free working example to try first.
- **A second agent for missed calls** is built but not released yet, so it stays on a waitlist.
- **The website** has animations, a pricing page and the chat widget itself, deployed on Vercel.
- **Lead-finding tools** that build the list of businesses to contact: see [Lead-finder tools](/projects/lead-finder-tools).

## What I learned

**Honesty is the product.** The brand promise is to be honest about what's real today. We never describe an unreleased product as available, and the site had to be checked line by line because the same fact (a price, a feature) lived in several places and drifted apart. One change means checking all of them.

**Keep a dated backup before touching a live site,** and always know where it is.
